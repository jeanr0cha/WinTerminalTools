## WinTerminalTools v2.2.0

Atualização automática pelo próprio app e preparação para distribuição via Winget.

### Downloads

| Arquivo | Para quem |
|---|---|
| `WinTerminalTools.exe` (~62 MB) | **Recomendado.** Executável único, sem ZIP: funciona em qualquer Windows 10/11 64 bits, sem instalar nada. |
| `WinTerminalTools-v2.2.0-win-x64-completo.zip` (~57 MB) | O mesmo executável completo, compactado. |
| `WinTerminalTools-v2.2.0-win-x64.zip` (menos de 1 MB) | Exige o [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0). |

Abra o `WinTerminalTools.exe` (nos ZIPs, extraia antes). Na primeira vez o Windows pode mostrar "O Windows protegeu o computador": clique em **Mais informações → Executar mesmo assim** (o executável não tem assinatura digital paga).

### Novidades

**🔄 Atualização automática portátil**
- Ao abrir, o app verifica em segundo plano se existe uma versão mais recente no GitHub Releases (sem travar a tela e sem erro caso esteja offline).
- Quando há novidade, aparece um banner discreto no topo com a versão disponível e o botão **Atualizar agora**.
- Com um clique, o app baixa o novo `WinTerminalTools.exe` com indicador de progresso, valida o executável, fecha, substitui o arquivo e reabre já atualizado.

**📦 Integração com Winget no workflow de Release**
- O workflow `.github/workflows/release.yml` agora suporta atualização automática do pacote `jeanr0cha.WinTerminalTools` no repositório oficial do Winget assim que o secret `WINGET_TOKEN` estiver configurado.
