# 📚 Documentação do projeto

Documentação geral do produto (vale para todos os repos). Cada repo guarda só o próprio `README.md`
e `AGENTS.md`.

| Pasta | Conteúdo | Gerado por |
|---|---|---|
| `business-context/` | o que é o produto, público, regras de negócio, estratégia | `/docs-build-business-docs` |
| `technical-context/` | arquitetura, infraestrutura, como os repos conversam | `/docs-build-tech-docs` |
| `specs/` | backlog, features e tarefas | `/product-collect`, `/product-feature` |

Sessões de desenvolvimento (o "onde parou" de cada feature) ficam em `.agents/sessions/`.
